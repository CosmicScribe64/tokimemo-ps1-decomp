# Tokimeki Memorial English patch: proportional Latin font, 12 px rows (T-39502).
# Our own drawing for the patch, not taken from the game or any other font.
# Source of tools/english_font.py, which writes the glyph bitmaps, the code map and
# the advance table for the English build, and a width table for build-time word wrap.
#
# Format: `glyph 0xNN <name>` (the single-byte code), then 12 rows of `.` (clear) and `#` (ink),
# all the same width (1 to 11 pixels). The advance is the width plus one pixel of spacing,
# unless the header line ends with `advance=N`. Row 0 is the top of the 12 px cell;
# capitals and digits sit on rows 1-9 (baseline under row 9), lower case x-height is rows 4-9,
# descenders use rows 10-11. Codes 0x20-0x7E are ASCII; 0xA0-0xDF hold extra symbols
# (the half-width katakana range of Shift-JIS, which the game's font never had).

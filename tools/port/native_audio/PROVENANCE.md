# Native audio provenance, build and licensing ledger

Production candidate sources are core.hpp, gaussian.hpp, extension.cpp and the four bgm_*.gd scripts; export_first_arrival.py is the importer helper. Tests/copies/evidence are separate. All are ignored pending review. There is no Redux source or diagnostic shared library in this runtime directory. This is independently authored code, not a formal clean-room claim: the earlier diagnostic reference was examined in previous work.

The CPU, ADPCM, Gaussian and ADSR behavior derives from project-owned NativeSdkProbe/sequence_pcm models and original instructions from the user's files. No original EXE instructions, VH/VB/SEQ data or whole captured memory are embedded in source. gaussian.hpp is a numeric hardware coefficient table, generated after verifying the compact table SHA256 191fa485f6a4a72cfdf660432e09db192133d7c48bec5d5b9a6f70cd591a7df8. Reverb code was authored using the register equations and numeric FIR facts at https://psx-spx.consoledev.net/soundprocessingunitspu/#spu-reverb-formula and the reverb-buffer-resampling section. No external explanatory prose or GPL DSP implementation was copied. Hardware phase/rounding fidelity is unaccepted.

# Decoder research references

These are unchanged upstream source snapshots used to compare numerical models, not game data or project implementations. Each adjacent provenance JSON records its exact upstream URL, revision and content hash. Original copyright and license notices remain in each file. Their upstream licenses apply separately from this repository's project code:

- DuckStation MDEC: CC-BY-NC-ND-4.0, Connor McLaughlin; see the source SPDX notice and its pinned upstream URL.
- MAME MDEC: BSD-3-Clause, smf; see the source license/copyright notice.
- PCSX-Redux MDEC: see its retained copyright and GPL notices.

The adapted executable comparison harness is local-only under ignored `.asset-cache/mdec-reference/` and is not published. The project's independently expressed numerical model is in `tools/assets/image_mdec_model.py`; model agreement is not hardware certification. See `wiki/port-adversarial-review.md` for scope and limitations.

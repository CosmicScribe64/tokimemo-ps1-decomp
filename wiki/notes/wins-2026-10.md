# Matching wins, waves 8-11 (2026-10)

93 functions, 125,820 bytes (ELF symbol sizes), matched on 2026-10-22 and 2026-10-23: wave 8 (T-251xx), the wave 9 closers (T-25201), wave 10 (T-253xx), wave 11 (T-254xx), the stubborn-function attack (T-25502) and diman8's PRs #68 to #70 (T-11900, T-11910). GEKO `func_80132B24` was matched twice (PR #70 and T-25401) and is counted once. [[tickets/T-25700-distill-wins]] made this page and the [[playbook]] recipes from it.

Each row names the change that decided the match, the [[playbook]] section that holds the recipe, and the note. A matching-notes section names its drafts `NOTES.md`, which hold the measurements and negatives. "FAKE" marks a construct that is there only for codegen (CODING_STANDARDS.md 7); "plain C" marks a row whose note reports no FAKE. Register symptoms are also in [[register-cheatsheet]]. Rows marked "one-off" have no playbook recipe.

## What the last 93 matches teach

Ordered by how many matches the lever decided (the group in the tables below). "Used in" counts every match whose fix used it; a match used about three levers on average.

1. **Write loops the way the original did: index loops, the original's counters, `for`.** Decided 18, used in 30. m2c prints loops after uopt's strength reduction (pointer walks, cursors), so the draft hides what uopt should derive from `p[i]`, `x[i << 1]` or `base + i * k`. Signs: the preheader sets saved registers in register order, spills sit below every declared home, a `.noalias` is missing, or the loop bound shares the base's register. Which counter runs which loop decides unrolling and colours. [[playbook]] 14.
2. **Decide which values are locals.** Decided 13; a frame fix (declaration order, a FAKE pad) was part of 40 of the 93 matches. A local the original did not have costs a declared slot or a range: delete it and repeat the expression (ETC `func_801328A4`, RPG_BAT `func_80154DD8`), or give a value a second use so it gets its own range (main `_sprite_set_light_effect1`). [[playbook]] 2, 7.
3. **Choose the access path.** Decided 10, used in 32. A read through `GameState *g` or a work pointer is an indirect load: stores through the pointer may alias it (reloads), it is not copy-propagated (one range), and `g->` next to an absolute read of the same field gives two expressions. [[playbook]] 3.
4. **Fix the types.** Decided 8, used in 28: `s32` with no return, implicit-int callees, value-returning views of void library calls, extra call arguments, `(s32)` on a u8 index, bit-field views. `viewsweep` and `funcdiff --proto` find most of them. [[playbook]] 1, 11, 12.
5. **Define the unit's own data in C.** Decided 7, five of them with no change to the function body. A function named by a `.data` table in its own file is an address-taken label to as1. Check this first when the only rows are as1 slot fills near a jump-table switch. [[playbook]] 5.
6. **Neighbouring globals are one object.** Decided 7, used in 12. Reaching a neighbour through the same symbol keeps as1's load/store order. A loop store that may alias (a record member, an indexed member of one struct) makes uopt reload what it would otherwise hoist past a loop guard. [[playbook]] 3, 5.
7. **Block copies need ugen_pass state F.** Decided 6. A never-true `istr` plus signed-loop arm, or a signed empty test after an `istr`, closed all six copy-state misses. One of them is main `strCallback`, which T-25118 had filed as a tooling gap. [[playbook]] 10.
8. **Never-true arms are the priority dial.** Decided 5, used in 20. A `(u32)x < 0` test survives uopt and vanishes in ugen: it adds a use, extends a range into an arm, adds blocks, or sets the copy state. All FAKE. [[playbook]] 13.
9. **Source lines and macros.** Decided 5, used in 15. Write libgpu macros (`setXYWH`, `setUVWH`, `setRGB0`) as one comma statement each before register work. as1 groups by source line and breaks ties by it, and a `#line` pair (FAKE) wins a tie that no layout reaches. [[playbook]] 5.
10. **The rest:** operand order (decided 4, used in 21), cvt_pass rules (3, used in 7), uopt block counts and splits (3, used in 4), switch and branch spelling (2, used in 14), `volatile` (2, used in 3). See groups 10 to 14.

How the work went:

- About a fifth of the matches started from a matched sibling's spelling (same file, or the twin scene in another overlay: GYOZI and VALEN) instead of from m2c.
- The hardest closers came from traces, not spelling searches: regdiff's R9 lines, uopt's spill order (`spilltemps`), `as1 -xbbdbg 8`, binasm and ucode dumps (T-25201, T-25137, T-25306, T-25314, T-25302).
- A toy file with only the function compiles in seconds where the whole unit takes minutes (main `func_800455C4`, `make_color_bar`, TAIIKU `func_80137784`).
- TAIIKU `func_80137784`, open since T-24521, was an index test that uopt had rewritten as a pointer compare. Three passes had looked for second symbol names instead. Before asking for a symbol or tool change, check whether a uopt rewrite explains the shape ([[playbook]] 4).

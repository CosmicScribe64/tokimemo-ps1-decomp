## Goal

Roadmap phase 2, unit `core`: name the shared state and types that every other unit uses, and write the port spec for it. Scope is the port-first one of 2026-10-24: game logic, state and flow in full; the hardware layer at module level with its entry points. This pass writes tables and wiki pages only; `src/`, `include/` and the symbol files are not touched.

## Acceptance criteria

- [x] `config/renames/proposals/core.tsv` with one row per rename (func, data, field, type, file, const) and `comment` rows for the O.BIN and patch names that stay.
- [x] Every `GameState` member covered by offset in [[spec/core]] (131 renamed, 30 kept as `unk_XX` with a reason).
- [x] The 73 types of `include/game.h` and `include/main_api.h` plus 12 file-local views of `src/main` have a decision (75 renames, 10 kept).
- [x] First enums proposed as `const` rows: girl id, parameter, month, weekday, club, place, health state, vacation, day kind, calendar marker, day event type, main mode, input and settings values, pad bits.
- [x] The 100 most used main functions named or commented (counts without EVENT and GYOZI).
- [x] HYPOTHESIS marks on every guess (74 rows).
- [ ] Review of the table and spec (names, evidence, marks) before the apply step.

## Notes

- Method: matched C and decoded data tables as evidence; uses counted with `D_800E6280.` field greps and a call-site census of `src/` and `include/` (EVENT and GYOZI excluded: they were linked against another main layout, so their main addresses are stale; this changes the top-100 list).
- Findings worth reviewing first: `unk_1108/1109/110A/110D` are mode/stage/step/substep with a full reset matrix; `unk_0F4` is the player flag word (health state, club, flags); `unk_F68` holds the last weekday and holiday commands; `unk_044` holds two month tables loaded from disc blobs (`D_800B3748`); `unk_71E` records played birthday scenes; `unk_720..722` is the return triple; `CharFlags.f20` is the girl's club id; the girl-score formulas are in spec section 5.2.
- Convention for `comment` rows: `old` = existing name, `new` = the English one-liner, `note` = evidence.
- `field` rows use the pre-rename type name as scope; apply them before the `type` rows.
- No emulator run: the `tokimemo-emu` image is not built in this tree (about 40 minutes and 8 GB); the open questions in the spec name the points an emulator check would settle.
- `[[tickets/T-27000-phase-2]]` is the parent ticket named by the task; it does not exist in this worktree yet.

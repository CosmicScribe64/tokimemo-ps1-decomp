**Decisions and limits:**
- SDK calls (`OpenEvent`, `TestEvent`, `_card_*`, `open/close/read/write/format/delete`, `rsin`, `abs`, `rand`, ...) are called by symbol name with `call_c`; nobody lists them, so they refuse until a backend exists (facade request below). Unnarrowed stub/SDK results are narrowed in the port where the C reads them as signed (`Math.s32`: `open`/`read`/`write`, `rsin`, `rand`, `abs`, `SquareRoot0`, `getCDlevel`).
- Blocking waits: `Hw_Test` and `memory_card_status_wait` spin on card hardware; they are bounded (0x4000 polls) and stop at a refusal; `memory_card_check_poll` step 0x20 calls `func_800AD950` (`VSync(0)`), which refuses by name.
- `hud_save_slot_info_show` calls `strncat(club_name_text, club_name)` with two arguments in the C, so the count is the stale a2. Captures `wpc-sn-save` and `wpc-sn-load` list `strncat` as a callee and record its arguments: a2 was 8 at both club-name calls (and the 2/4/6/13/8-valued calls elsewhere are the explicit counts). The longest `club_name_table[0..11]` entry is 8 bytes (サッカー), so a count of 8 copies every name whole; the port uses 8 (`CLUB_NAME_STRNCAT_COUNT`). The observation is from OpenBIOS `strcpy`; with the retail BIOS the leftover is not observed.
- `hud_magazine_page_build`: `magazine_issue_index` is uninitialised in the C unless a year/month arm sets it (year 0x62 with months 5-12, year 0x5F with month 1, months outside 1..12, years other than 0x5F..0x62). The port keeps -1 and refuses by name at the first use ("magazine_issue_index is uninitialised for this year/month"); hand-checked.
- `hud_appointment_add` with all eight entries active reads and writes entry [8] (`scene_flags` word 0) as the C does (tested).
- Undefined C return values: `menu_check_2` returns `&game_state + (count[menu] != 0 ? menu : 0)` and `girl_points_others` returns `sp + 0x5E` (leftover v0, read off the asm); `menu_check` and `girl_scores` pass them on. These four no longer carry `ret_undefined`: the harness compares `v0` and the 56/64/12/12 hits pass. The other `ret_undefined`/`ret_defined` functions (`menu_set` success path, `girl_points_shiori` final path, the three bank builds/load, `hud_text_marker_bob`, `hud_magazine_mark_read`, `portrait_event_face_*_start`) return 0 as an unobserved placeholder; every caller discards the value.
- `calendar_month_load`: three narrow per-function exclusions in the spec: 0x800DD680 (20 bytes, libgpu queue state), 0x800E3450 (148 bytes) and 0x800E35FC (4 bytes), both libetc interrupt-handler state; they change under interrupts while the function runs, the port never writes there.
- Unreached blocks (`--cover` captures `wpc-cov-a`: notebook mash from `select-0528.sstate`; `wpc-cov-b`: TEL `tel-shiori-0x45.sstate` mash, 1500 frames, 20 hits per function; `coverage.sh`): `menu_check` 26/65 instructions, unreached blocks 0x8004F9A4 0x8004F9C4 0x8004F9CC 0x8004F9FC 0x8004FA00 0x8004FA08 0x8004FA10 0x8004FA28 0x8004FA3C 0x8004FA44 0x8004FA4C 0x8004FA60 0x8004FA68 0x8004FA70 0x8004FA78 (the menu_mode 1/2/3 arms; mode 1 is covered by the earlier differential captures, modes 2 and 3 only by `menu_speaker_girl_test.gd`); `menu_cursor_update` 92/453 (108 unreached blocks from 0x8004FC44, modes 2 and 3 and the wrap/skip loops; those the 64 differential hits reach are covered, the rest by hand checks); `sndi` 195/263, unreached 0x8005114C 0x80051154 0x80051170 0x80051180 0x8005118C 0x8005119C (the style-15 `P`/`G` expansion), 0x800512A0 0x800512A8 0x800512E8 0x800512F4 0x80051300 (rows 0 style 0x1F/0x2F/other), 0x80051354 0x8005136C 0x800513A0 0x800513B8 0x800513DC 0x800513E0 0x800513EC 0x80051404 0x8005140C 0x8005141C (rows 1/2 with style 0xFF). No voice-on state was reachable without poking the voice setting, so the voice-on paths of `talk_text_step`/`talk_voice_play` are hand-checked only.
- `MEMCARD_DIR=<dir>` (path relative to the data root or absolute) for `tools/emu/func_capture/run.sh`: copies `memcard1.mcd`/`memcard2.mcd` from that directory into the capture's output directory so the emulated card starts with that content (the source is never touched); without it the cards start blank. `CONTAINER_PREFIX=<p>` renames the container to `<p>-<name>` (here `wpc`) in `run.sh` and `run_engine_diff.sh`. Please document both in `wiki/emulator.md`.

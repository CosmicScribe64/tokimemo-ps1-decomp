## Notes
- Identity: ETC is a grab bag of seven scene entries: final exams (0x35), career guidance (0x36), career choice with the entrance exam (0x37), and the ending tail staff roll (0xC2), last photo (0xC3), clear save (0xC4) plus the photo album (0x91). The core placeholders `MODE_ETC_C2..C4` become `MODE_STAFF_ROLL`, `MODE_LAST_PHOTO`, `MODE_CLEAR_SAVE`.
- Prefix decision: the knowledge base proposes the lower-case overlay name (`etc_`); here every scene gets its own English stem (`exam_`, `career_guidance_`, `career_choice_`, `staff_roll_`, `last_photo_`, `clear_save_`, `album_`) and `etc_` stays for shared leftovers. Source folder `src/ovl/etc/`.
- Result: 779 rows: 394 function, 233 data, 114 const, 18 field, 14 file (13 `.c` files and the header), 6 type; 5 start with HYPOTHESIS. The 651 func, data, field and type rows pass `tools/rename.py plan` (file and const rows are applied by their own subcommands).
- Settles core questions: `girl_cleared` is a per-girl ending counter (cap 99, saved in the system file); `PlayerFlagBits.b16` is the remedial week flag (set by the exam results after 3 red marks, with calendar marker 0x17 for tomorrow); the career result byte in `player_flags_hi` byte 1 has bits 0-5 for the accepted university or company tier, 0x40 club dream, 0x80 failed.
- Dead code found: three developer stub scenes (25 functions), two skip-week helpers, an album test fixture, three unused animation table setters.
- Port-first scope: game logic fully named; the draw, VRAM, CD and sound layers only by module and entry point. The 72 album animation packs are named by scene id (formulaic rows).
- Emulator: `tools/emu` with a local poke wrapper in `build/emu/` (not committed) started each ETC mode directly from the title-menu state. Printed values confirmed the exam score formula and the ranking arithmetic (`func_800A0140` is cosine); screens confirmed the staff roll, last photo, save prompt and the four-photo album page.

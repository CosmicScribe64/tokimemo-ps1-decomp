## Goal

Roadmap phase 2: make the matched code readable, port-first. User scope (2026-10-24): "not 100%, just enough
for the Godot port". The game logic is named and explained in full, the PS1 hardware layer only at module level
and entry points, locals and hex literals only where essential, SDK names optional. Names are backed by
evidence (`docs/adr/0001-phase-2-naming.md`, section Scope). Plan and work order: [[phase2]]. The matching
decompilation stays exact: every change keeps the build at 27/27 sha1 and 6,952 matched functions.

## Acceptance criteria

- [x] Conventions decided and written: ADR 0001, CODING_STANDARDS sections 4 and 5, `GLOSSARY.md` (T-27001,
      Done).
- [x] Rename tool with ledger, replay and check (T-27002; merged).
- [ ] O.BIN names reach the overlays; alias debt cleared (T-27003).
- [ ] Shared core named: GameState fields, core types, first enums, top 100 main functions (T-27004).
- [ ] Game logic named and explained in every main module (M1-M9) and in all 26 overlays: GameState and
      records, enums, calendar and schedule, parameters, girls with affection and tokimeki, day events and
      scenes, dates, confession and endings, save data, each overlay's state machine and data tables; port
      specs in `wiki/spec/` for the overlays.
- [ ] Hardware layer (GPU, sprites, VRAM; sound driver; CD and XA; MDEC) named at module level and entry
      points; every module and overlay has English file and header names.
- [ ] Locals, parameters and constants named where they carry game logic (ids, flags, thresholds).
- [ ] `include/main_api.h` and `include/game.h` deleted: every C file includes the topic headers it uses, and
      CODING_STANDARDS section 8a and `tools/check_headers.py` name the topic headers.
- [ ] Final sweep: `count_names.py` residue per layer. Game logic has no placeholder left except unused or
      unknown fields and jump tables; hardware-layer and SDK residue is listed, not required to be zero.
      Current wiki pages use the new names (old names stay in tickets, logs and old notes).
- [ ] The matching build stays exact: 27/27 sha1 and `ninja progress` at 6,952 after every change.

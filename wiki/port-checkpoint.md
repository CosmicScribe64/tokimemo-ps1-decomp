## Remaining fidelity deviations (P3.6 disclosure)

Per `[[phase3]]` Milestone `P3.6` (`wiki/phase3.md:183`), all native calendar/scheduler/overlay rules, 320x240 HUD/VN composition, save/load projections, and code-only desktop packaging are verified, with the following explicit architectural fidelity boundaries documented between the native PS1 hardware and the Godot 4.7.2 port:

1. **Software MDEC `.BS` / `.STR` Macroblock Color Conversion Tolerances**: Extracted `.BS` still backgrounds and `.STR` motion frames use software IDCT + YCbCr-to-RGB conversion (`tools/assets/export_media.py`), which can differ by `+-1` LSB in 24-bit RGB rounding compared to the PS1 hardware MDEC + 15-bit `RGB555` VRAM quantization prior to `4x4` Bayer dithering. All paletted 4bpp/8bpp `.NBN`/`.NPK` HUD sprites, bust-ups, and 1bpp `FONTX` glyphs are 100% bit-exact (`0 / 300` `16x16` tile hotspots in `tools/port/verify_tile_diff.py`).
2. **Event-Driven Resource Completion vs. 1x/2x CD-ROM Mechanical Seek Cadence**: `GameSession` (`port/godot/core/game_session.gd`) preserves the exact PS1 `VSync` state machine and `ServiceEvent` (`BEFORE_MODE` / `AFTER_MODE`) phase boundary (`cd_read_is_busy` / `cd_queue_Wait`), while reading extracted external asset packs asynchronously from host storage rather than emulating physical 75-sector/second CD-ROM rotational seek jitter. Differential traces inject deterministic `ServiceEvent` completion frames to match PS1 emulator frame counts bit-for-bit.
3. **SPU Voice / Reverb & SEQ Playback Boundaries**: `tools/assets/export_media.py` decodes PS1 ADPCM `.VAB`/`.VB` voice banks and `.XA` streams to PCM `.wav` and parses `.SEQ` sequences (`BGM.NPK`, `DATA1.NPK`), while runtime playback routes through Godot's software audio mixer rather than cycle-accurate PS1 SPU hardware Gaussian pitch interpolation and IIR reverb registers.
4. **Release-Profile Scope (`T-29017`)**: `tools/port/import_game.py` and `port/godot/core/disc_importer.gd` validate all 5 cataloged PS1 releases (`SLPM-86053` PlayStation the Best v1.2 primary reference, `SLPS-00067` Rev 0, `SLPS-00067` Rev 1, `SLPM-80025` Demo, and `SLPM-86226` Konami the Best) via explicit per-release LBA/SHA256 profiles; unprofiled bootlegs or modified ISOs are rejected at the import boundary.

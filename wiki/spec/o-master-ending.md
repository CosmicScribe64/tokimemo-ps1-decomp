# Club mastery and endings (MASTER + ENDING)

This is a source-backed port-planning slice with a complete function-definition pass and a partial overlay-data inventory. The disc map assigns MASTER `master_` and ENDING `ending_`; shared words such as `confession_` and `epilogue_` are not overlay prefixes in the ADR and must not be used as row prefixes. O.BIN identifiers remain untouched. Current applied core identifiers are used below, including `game_state`, `mode_stage`, `mode_step`, `day_event_done_bits`, `player_flags`, `clubs`, and `event_log`.

## Club tournament / mastery flow (MASTER)

`func_80132140` dispatches `mode_stage` through `D_8013C2E4` (four callbacks). The callbacks initialize the award scene, choose tournament-class dialogue pointers, present a selected companion, commit award changes and append event-log data. `func_80139150` dispatches a separate seven-stage sequence through `D_8013C798`. In the final-grade sequence, class selector values 7–10 choose the background and actor-resource set. The stage computes `club[player_club].practice_points - 350`, maps the signed margin to grade 0–5, shuffles five result markers, and presents the result. The selector then drives companion dialogue, event-log class flag and final exit. These roles are established by the stage callers and callback bodies; labels for the narrative dialogue remain unresolved.

In `func_801391E4` (`src/ovl/MASTER/club_master_scene_and_tables.c`), `mode_step` drives setup and result selection. At step 2, after CD readiness, it first calls `func_8008647C()` for a candidate and checks Rei (`girls[0xC]`) flag byte at index 3 against `0x41`. Otherwise, if the initial candidate rank is below 2, it selects eligible met/active girls whose rank is below 2 and whose club nibble (girl flags byte 2 >> 4) matches the player's club selector (`player_flags.h >> 12`). The loop overwrites the candidate, so the last qualifying index wins except for the explicit 0-versus-10 comparison. If both 0 and 10 qualify, rank eligibility selects the sole qualifying one; if both qualify, affection+tokimeki totals are compared and `>=` favors index 0. If initial candidate rank is not below 2, Miharu (index 11) is selected when her `flags.b[3] >= 2`; otherwise the selector becomes `0xFF`. The selected value `D_8013C790` is subsequently used for voice, portrait and current-girl setup, so this is named candidate selection rather than winner selection. These directions and the tie sign are directly established by the conditions in the body.

`func_8013B20C` is the result exit. Once its audio poll is ready, it sets `game_state.day_event_done_bits |= 0x10`; only when `D_8013C784 >= 3U` does it set `clubs[player_club].b30 = 1`, then it calls `day_event_next(1)`. The flag is strongly indicated as club mastery state by the code context and glossary, but its exact semantic bit name should remain open pending corroboration. A result-log helper (`func_8013B448`) appends scene `0x15` and the current date/girl to `event_log` before a tournament-class switch.

In `func_801391E4`, step 6 only calls `normal_date_speak()`. The practice-point margin is in `func_80139CC8` step 6: it computes `clubs[player_club].practice_points - 350` and maps it to `D_8013C784`: below -30 => 0; [-30,-21] => 1; [-20,-11] => 1; [-10,-1] => 2; [0,9] => 3; [10,19] => 4; [20,29] => 4; 30 or more => 5. (The consecutive intervals simplify to < -30:0, [-30,-11]:1, [-10,-1]:2, [0,9]:3, [10,29]:4, >=30:5.) `func_8013B20C` awards club `b30` when that score is at least 3, equivalent to practice points >=350. So the source establishes an effective practice-point mastery cutoff even though the stored bit's other uses and game-facing label remain to be fully cross-checked.

Other visible branches: in `func_80139910` the selector `player_flags.h >> 12 == 7` skips a background read and place movement; `func_80139810` starts a portrait read unless candidate is `0xFF`, otherwise advances without it. Their exact event labels are not asserted here.

The Koshien and companion portion in `src/ovl/MASTER/club_tournament_scene.c` is also body-reviewed. Its 30-entry stage dispatcher feeds a Koshien scene that snapshots met-girl flags and increments club 6's `unk_25`; the paired grade scene compares club 6 practice points plus `param_guts >> 4` against the stage threshold table and stores a 0–5 grade. Grades 3–5 advance the tournament and award all girl entries 0–12 at the observed stage-specific amounts. The companion chooser checks Rei (girl 12), active/rank-eligible girls and class ties, then Miharu (girl 11), or stores `0xFF`; subsequent portrait and dialogue setup uses that selected companion. The selector does not identify the tournament winner. A later reward callback adds five tokimeki to girls 0–12 and sets club 6 `b30` for grade 3+, and adds two affection to a selected companion. The scene callbacks append event log scene `0x15`/flag 6 records; rank and weekday values vary by the selected girl as written in each helper. The birthday gate and player-birthday state machine check packed calendar dates and the once-per-day bit before starting their scenes.

## Graduation candidate selection (ENDING)

`func_80132334` dispatches stages 0 through 7 to callback groups; the default runs `func_80132400`. Stage names are scene-level roles, so only the dispatcher receives a proposed name in this slice.

`func_801330E4` fixes the graduation date to year `0x62`, month 3, day 1, Sunday, then calls `func_80053418(rank, points)`. It starts with Yoshio. Rei (index 12) wins the special branch only if `points[0] < 500`, `girls[12].flags.b[3] >= 70`, and `scene_flags[0x4F] == 2`. Otherwise, indices 0..10 are considered in order, and a met girl replaces the current best only when `points[i] > best`, with best initialized to 499. Equal scores do not replace the earlier winner. If no score exceeds 499, Yoshio remains selected. Only then, when Yoshio remains, a Miharu selection is possible: level is girl 11's story stage plus 2 for each positive scene flag 0x4C and 0x4E, clamped at 17; the chance test runs only when the story stage is nonzero and scene flag 0x4D is zero, and selects Miharu if `rand() % 256 < D_8013C3B0[level]`.

The next callback `func_80133460` either advances mode_step or, when candidate index is at least `GIRL_YOSHIO` and girl 14's `flags.w` bits 9..11 are below 3, sets mode_stage 7 and `D_800E7D34` bit 3. The selected-candidate/flag relationship is not fully decoded. Later `func_80139A58` explicitly sends Yoshio to stage 7, step 15 and every other candidate to stage 8.

`func_80137730` samples CD audio level during the ending: it reads `getCDlevel()` when `cd_audio_state() & 4` is nonzero (otherwise it uses zero) into a four-frame ring. It selects the maximum using strict `<`, then the second-largest value excluding the selected max slot, also using strict `<`; ties preserve the earliest slot visited. It compares that second maximum against the current girl's three threshold bytes (first threshold forced to 8) to derive a level. It reverses a nonzero level as `3-level` only when both `current_girl == GIRL_SHIORI` and `D_8011F522 == 8`. The separate selector setup maps current_girl 9 (Megumi) to value 8; that mapping alone does not trigger the reversal. If a prior result is nonzero and the frame tick is odd it holds the prior value; otherwise it writes zero for no signal/level, or level 1, 2, or 3 into `D_8011F524`. This describes the explicit audio-level and threshold processing; what the level represents is unresolved.

## Additional body-backed state rules

MASTER's asset setter functions are selected by the same player tournament selector used by the event flow: selector values 7, 8, 9, and 10 call `func_80139054`, `func_801390FC`, `func_801390A8`, and `func_80139000` respectively. Each installs the scene's three source pointers, a halfword read, and a shared source pointer; semantic labels for those assets remain unresolved. `func_80139CC8`'s mode-step case 6 computes `club.practice_points - 350`; its exact boundaries map to grades `<-30:0`, `[-30,-11]:1`, `[-10,-1]:2`, `[0,9]:3`, `[10,29]:4`, and `>=30:5`. Exit awards the club's b30 field only for grade >=3, equivalent to practice_points >=350.

`func_80133374` is the tournament reward commit: it sets day-event completion bit `0x10`, adds `0x14` tokimeki to girls 0..12, adds 2 affection to the selected companion when the selector is not `0xFF`, sets the selected club's `b30`, appends the event log via `func_8013348C`, and advances the day event. `func_8013348C` records scene `0x15` and a class-derived event flag; class 1 distinguishes qualifying girl 0/1 cases. This result bookkeeping does not establish that the companion won the tournament.

The player-birthday scene (`func_80138490`) checks the player's packed birthday against the current month/day and handles the already-completed/rank gates before staging the Shiori dialogue. In the response branch, selector values 0 and 1 raise Shiori tokimeki/affection and reduce syoushin; value 2 raises affection by one and syoushin by ten. It records event scene `0x15`, flag 6, then moves to the next day event. These three branches are literal response outcomes; their natural-language labels remain unresolved.

`func_80136EE4` selects ending scene sectors and resource-pointer setup from `current_girl`: Shiori, Yuina, Ayako, Saki, Yukari, Mira, Yuko, Megumi, Yumi and Miharu have direct branches; Mio has separate `flags.f.b14` branches and Nozomi uses `girl_cleared[6] & 1`; all other values use the default set. The scene pointer setters install animation/still-image pointers, a halfword from the asset block, and texture-page addresses. Those names identify the selected girl/set only; the artwork's story meaning is not inferred.

`func_80137160` uses the supplied resources to configure two actor records, then sets `D_8011F522` to default 7 or selector 4 for current_girl 1/3/12, 5 for 2/8/11, 6 for 4/10, and 8 for 9 (Megumi). `func_80137730` reverses the derived level only when `current_girl == GIRL_SHIORI` and selector 8 is active. The setup mapping for current_girl 9 (Megumi) to selector 8 is a separate fact; the reversal still requires Shiori.

`func_80137AA8` dispatches `current_girl` to a per-character audio-scene updater: Shiori, Mio, Yuina, Ayako, Saki, Yukari, Nozomi, Mira, Yuko, Megumi, Yumi and Rei have explicit cases; other values use the default handler. Each updater reads the event step (`D_8013C35C`), its tick (`D_8013C360`), sampled audio-level state and actor sequence fields, then calls `func_801396A4` to change audio/text state. Mio's three event-step positions are offset according to girl 1 `b14`. The scene timing and actor/audio transitions are preserved literally; no rhythm or performance meaning is assigned.

The shared ending dialogue interpreter uses `D_8013C358` as page and `D_8013C35C` as step into `D_8013C34C`'s text/kind/voice tables. `func_80132420` handles title kinds 0 and 6, spoken kinds 1 and 0xC, waited spoken kinds 0xD and 0xF (waiting 0x3C ticks), and terminal kind 0xFF. It starts optional CD voice playback from the page/step range table and waits for audio completion before reporting a finished line. `func_80132B04` advances step or page only when the caller allows it and its text/voice wait flags clear; kind 0xFF advances the page and resets step. This defines control behavior without assigning narrative labels to the numeric kinds.

`func_8013A2E8` builds graduation result dialogue from player outcome bits, club `unk_25` values, seven `param_liberal_arts` results, and progress values 0x15..0x1C. The career result bitfield selects a displayed university/company label; otherwise club fields >=3 select the first matching club label. Progress entries 0..5 are compared directly, entry 6 is compared at 3/4 weight (the stored `top` assignment is half the source value), and entry 7 is compared at half weight. For the no-club-reward branch, a best parameter score below 0x78 chooses a lower-result dialogue kind; otherwise `bestGirl` selects a category. The chosen `kind` plus `current_girl` selects one response text entry. This function selects and renders result dialogue; it does not change the graduation candidate or persist outcome values.

The named ENDING candidate helper sets the calendar to year 0x62/month 3/day 1/Sunday. Rei is index 12 and Miharu is index 11. The Rei special branch is checked before ordinary met-girl ranking; the ordinary ranking loop visits indexes 0..10 in order and uses strict greater-than, so earlier ties remain selected. The Miharu chance level uses her story stage plus two for each positive scene flag at 0x4C and 0x4E, capped at 17, and only evaluates the random-byte comparison when story stage is nonzero and flag 0x4D is clear. The helper returns a candidate identity; it does not establish a tournament win or final confession result.

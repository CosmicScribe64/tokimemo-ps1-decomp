# Register cheat sheet

One page for a register-only miss: find the symptom, try the C changes in order, rebuild and run `regdiff` again. The evidence for every rule is in [[uopt-register-allocation]], [[register-allocation-wave7]] and [[decompile-workflow]].

## The loop

1. Fix every non-register difference first (`funcdiff --resolve`). The register analysis only covers instructions that already agree.
2. Run `TOKIMEMO_SCRATCH=<scratch> tools/docker.sh python3 tools/regdiff.py [UNIT:]func`. Read only the `FIRST DIVERGENCE` block.
3. Make one change from the table below, then rebuild and run `regdiff` again. Repeat until it says `MATCH`, or you have tried every row that fits.
4. Near miss under about 20 lines: run `tools/permute.py --time 120`.
5. Still blocked: keep the draft under `#ifdef NON_MATCHING` and add a T-0018 row naming the regdiff hint.

## How uopt picks a register (the four facts that matter)

- **Priority** of a value is roughly (loads + stores) times loop weight, divided by how many blocks it spans. Loop weight is 10 per loop level. A value that is only stored once, or loaded once and reloaded, has priority 0 and gets no register at all.
- **Order:** in a function with calls, every value competes by priority, and the highest goes first. Ties go to the value the compiler numbered first. In a leaf function, values with few conflicts are coloured in that numbering order, not by priority.
- **Registers are tried in this order:** v0, v1, a0..a3, t0..t5, then s0..s7. The first free one wins.
- **t6..t9 and `at` belong to ugen, not uopt.** Their numbering follows expression shape and statement order. Allocator tricks don't move them.

## Symptom -> what to try

| regdiff says / asm shows | Try, in this order |
|---|---|
| **tie**: two equal-priority values swapped (constants, addresses) | The compiler numbers them by first use. Reorder the statements so the original's value is used first. In `a[i] = b[i]` the left address comes first; dropping a temporary (`v = b[i]; a[i] = v;` -> `a[i] = b[i];`) swaps the two bases. Ranges are numbered in ucode first-mention order, so writing `r2` before `b0` changed the colouring in `_sprite_set_box_shade_tarao` (T-16220). |
| **priority order**: the wrong value wins a register | Give the loser one more use, or the winner one fewer. Repeat an expression instead of keeping a temporary, or the reverse. Move a use into or out of a loop, since loop uses count 10x. |
| **extra or missing range**: the original keeps a value in a register that the draft recomputes, or the reverse | Add or remove a local for that value. A raw load in one register and a derived value in another means: declare the raw value as a local and repeat the derived expression. |
| one `li k` stored to several places in the original, separate `li`s in the draft | Chain assignment through elements: `a[0] = b[0] = k;`, or `(&A)[0] = (&B)[0] = k;` for two scalars. Separate plain scalars cannot share it. The same holds for a loaded value stored to several fields (with separate statements the value and its address share `$v0`): chain every target as an element of the real aggregate, `D_801217D0[57].unk_14 = D_801217D0[57].unk_15 = D_801217D0[57].unk_16 = ((DisplayRecord44 *)D_8011ECD0)[98].unk_07 = D_800B593C;` (DATE `func_801511B4`, T-16230). A plain scalar in the chain broke it. The store order of a chain is not simply right to left: when the stores come out shuffled, try the target orders. |
| `xori; sltiu; beqz`, or a switch-temporary copy `or v0,v1,zero` | Make the function `s32` with no `return` (K&R). Compare the old value: `if (D++ == k)`. |
| a `move`/`andi`/`li` into v0 near the end that nothing reads, or the outer targets of a chain stored from a v0 copy of the value | Make the function `s32` with no `return`: v0 is then live at the exit and uopt keeps the chain assignment's hidden temporary (or a promoted value) in it. Matched 5 functions in main 8007C030 (T-11590). |
| one extra ugen temporary after `x |= bit` on a flag byte (or one short, with `b[0] |= 2`) | Use a bit-field store: `((Bits *)&x)->f = 1;`. The one-short case: `.f.b1 = 1; .f.b3 = 1;` on a `CharFlags` bit-field (NAME_ENT `func_80139440`, T-11650). |
| GameState selector read after a call lands in the wrong register | `u8 state; state = D_800E6280.unk_X;` right after the call, then compare `state`. `u32` also works; signed doesn't. |
| `bne` operands reversed but the registers are right | A narrow local for the shared constant (`s16 one; one = 1;`, mark FAKE), or a `u8 sel` copy of the selector. A named `u8 eight = 8;` put the constant first in `func_8006A2CC` (`beq a1,t0`, T-11690); the new local must take an existing pad slot, or every spill slot moves down 4 bytes. |
| ugen temporaries shifted by one (`t7` vs `t8`) | Change the parameter's width: `u16` vs `s16` vs `s32` starts the temporaries at different registers. Also check statement order and same-line grouping (as1 schedules by source line). |
| `li a0,k; multu` with a0 reused afterwards | The index is a struct member, not a local (`D_800E6280.unk_F5F`). Also check that the callee really takes no argument. |
| stack argument stored in the `jal` delay slot | Index the array (`p[i]`, `i++`) instead of walking a pointer. |
| narrow parameter kept in its home stack slot | Use an old-style K&R definition, and declare the promoted locals before any buffer. |
| unsigned `% 240`-style chunk with one temporary too many (ENDING) | A dead test `if (x) {}` right before `r = x % 240;`. It's FAKE: mark it T-9410. |
| loads in a different order or place than the original, with several `D_` names close together | They are probably one array or struct. Write the accesses through one base (`D_X[i]`, `(&D_X)[k]`). That fixed load order in SHOUGATU `func_8013507C` and EVENT `func_80104D48` (T-10610). |
| switch on a global byte with an extra `cvt`/copy of the selector, or the selector in the wrong register across two tables | Read the selector through a scalar byte view: `u8 sel = *(u8 *)&D_X;` or switch on `((u8 *)&D_X)[0]` (T-10860, many matches). Write a promoted byte that the handler changes through the same view, with no local (`*(u8 *)&D_800E6280.unk_03A -= 4;`, NAME_ENT `func_80139684`, T-11650). The view of an already-`u8` selector keeps it in `$v0` (`func_801357F4`), and a `u8` view of an `s8` field gives the original `lbu` (`func_80067C28`, T-11690, which also needed a dead copy of its `max` loop; FAKE). |
| two live values share one register in the draft, the original keeps them apart (or the reverse) | An empty test `if (x) {}` or a dead compare local splits the live range (permuter finds these, T-10820/T-10850). Mark it FAKE. |
| a local holds a computed value in the wrong register (`a3` vs `v1`, a `v0`/`v1` swap), and the original stores that value to a global in every branch or right before each call | Assign the value to the global itself and read the global afterwards (`D_8011ECA0 = f(); ... D_8011ECA0 * k`, `D_800CA2A4[0] = g % 3; if (D_800CA2A4[0] == 0)`). uopt promotes the global, sinks its store into each branch and colours it like the original. Matched `func_800422C8` and `junban_init` after ten failed local-variable passes (T-16220). A promoted selection byte works the same way: read and write `D_8014CC70` directly in every statement, no local (NAME_ENT `func_80132B78`, T-11650). |
| byte stores of `x >> 16` / `x >> 8` reused twice sit in `t6..t9` in the original, the draft gives them `v0`/`v1`/`a0` | Mask them: `p->r0 = (c >> 16) & 0xFF;`. ugen drops the `and` for `sb`, so the shift stays a ugen temporary; plain shifts, chains and `u8` locals become uopt ranges (T-16220). |
| the original reloads a global after a store, the draft keeps it in a register | Store through a pointer or record view (`((Rec44 *)D_X)[96].f`, `gs->f`): uopt treats it as a possible alias and reloads. |
| the draft forwards a stored value (`$t9` temp), the original reloads | Use a compound assignment (`D_X += 0x48;`) instead of recomputing from the source. Also: `v = call(); v += k;` keeps the call result first in `addu`. RPG_BAT `func_8013AF1C`: `D_8015EDB4 += 3; if (D_8015EDB4 >= 0x21)` in both cases keeps the first load in `$v0` where m2c's temporaries give `$a1` (T-16210). |
| what stays in a register differs only around a `break`/`continue` | Join blocks decide it. Route the path straight to the shared tail (or add a redundant `break`) to match the original's block shape. |
| loop counter gone (strength-reduced) or a tail loop gets other s-registers | Write `(col << 4) - 0x80` instead of `col * 16 - 0x80` to keep the induction variable; reuse the earlier loop's `i` for a tail loop. |
| store order, delay-slot fill or `addiu` order differs, registers right | as1 schedules by source line: put the stores (or loop init and head) on one line, or permute independent store statements. Seen: a record triple written on one line, as from a macro (`func_8006A2CC`, T-11690); loop init on the `do` line and the loop body on the `for` line (NAME_ENT, T-11650). Reordering independent stores also renumbers ugen temporaries (TAIIKU `func_8013C978`: `D_801206BA` before `D_801206BE`, T-11640). |
| temporaries swapped in a sum (`u`, `v`, `clut`) | Try the operand orders of the sum; they set the ugen temp numbering. |
| frame size or local stack offsets differ | Arrays sit lowest in the locals area; scalars declared before an array go above it. Add unused locals ("homes") to reserve slots and mark them FAKE. |
| bit test compiles as `sll 30; srl 31` in the original | Bit-fields are allocated from the least significant bit: `struct { u32 low : 1; u32 f : 1; u32 rest : 30; }`. |
| reloads appear at a block start after about 20 references | uopt ends a block after 20 variable references (`varreflimit`). Split or join statements to move the boundary. |
| a counter or stored value right after a call sits in `$v0` where the original has `$v1` (regdiff: "an interfering range holds `$v0`"), and the callee is `void` in the header | The call's `$v0` result only exists for an `int` callee. Declare it `s32 f();` for this file only: define `RPG_BAT_OVERRIDE_<name>` before the includes (`MAIN_API_OVERRIDE_<name>` for a main-exe callee; the header wraps its prototype in `#ifndef`) and declare the K&R prototype in the `.c`. Matched RPG_BAT `func_801568A4` and `func_801454F0` (T-16210). Test it on a scratch copy with `regdiff.py --src`. |
| the loop counter, record base and count avoid `$v0` next to a call whose result the original ignores | The reverse: a value-returning call used as a statement blocks `$v0` in its block. Override the callee as `void f();` in the file (`MAIN_API_OVERRIDE_func_80053418`). Matched `func_8006EA40`; moved `func_80072998` from 16 to 14 lines (T-11670). |
| argument registers at a call differ from the prototype: the original sets up fewer arguments, or the draft loads an argument the callee never reads | Read the callee. Fewer arguments: declare it unprototyped, `void f();` through the override (strncpy `func_800AE090` with two arguments in `func_80133510`, T-11650). Unread argument: the register holds a promoted global, so make the callee `void f(void)` (`func_8013D9B4`, T-11640). |
| the draft fills a `bgez`/`beqz` delay slot with the fall-through `lui v0`, the original has a `nop` (or the reverse) | Make the function `s32` with no `return`. With `v0` live at the exit as1 may not hoist that `lui`. Fixed `func_80155A70` (T-16210) and the whole difference of `func_80135650` (T-11650); TACO `func_80133870` (the original's `move a1,zero` fills the slot of the `beqz` before the last call, T-16562). |
| a global is loaded as a split `lui t8; lw t9` (two different registers) in the original | Use the absolute address: `*(s32 *)0x8015ED98 & 0x100` instead of `D_8015ED98`. FAKE (RPG_BAT `func_8013AD50`, T-16210; `func_8013D030`, T-4010). |
| the original keeps `start` on the stack, copies it once (`mfhi t8; sw t8; move s1,t8`) and strength-reduces `(start + i) % n`; the draft has `mfhi a0` and every later t-register one off | Write `(start + i) % n` in the expression, with no separate `idx = start; idx++` local. Write the loop as `for (i = 0; i != 11; i++)`: a do-while puts the `li v1,11` reload before the increment. `func_80072D70` (T-11670). |
| a spilled local lands at the wrong offset though the frame size is right | Spilled locals take slots top-down in declaration order (first declared highest): declare the register locals first and the spilled ones last (`order_search.py` with `/* ORDER */` around the declarations finds it, `func_80150C78`, T-16230). A table 4-12 bytes under the frame top needs that many scalars declared before it (`func_8013FC5C`, T-11640). A pointer local can shift a spill slot 4 bytes: repeat `text + 0x20` in each call instead (`func_801338DC`, T-11650). A byte pad reserves a gap: `u8 pad[0x44]` above three buffers (`make_three_select`, T-16220; FAKE). |
| frame 8 bytes too large after `A[f()] = B[i] = v;` | A chain assignment whose index is a call adds compiler temporaries at the bottom of the frame. Use two statements, `A[f()] = v; B[i] = v;` (TAIIKU `func_80138AA8`, T-11640). |
| inner tests branch straight to the epilogue with `move v0,zero` in the delay slot; the draft has `bnez`/`b` pairs with `nop` slots | One `&&` chain over the outer and the inner tests, with a single `return 1` and a single `return 0`. Not nested `if`s or a second `return 0`. `func_8006EA40` (T-11670). |
| a decrement of a narrow field has an extra `andi a0,v0,0xff` (or `andi v0,zero,0xff` after a store of 0) | Do it through the `GameState` pointer: `if (gs->unk_71C != 0) gs->unk_71C--;` keeps the original `andi t3; move v0,t3; sb v0`. A `u8 idx` local adds the `andi`, and a forwarded `(u8)0` means the original re-reads the field instead of a local. `func_8006D6E0` (T-11670). |
| a 0x44-byte record copy ends with the last `lw`/`sw` pair in the other order | Copy elements of one array, `((DisplayRecord44 *)D_8011ECD0)[98] = ((DisplayRecord44 *)D_8011ECD0)[96];`, not two splat symbols (`*(T *)D_801206D8 = *(T *)D_80120650`). DATE `func_80150460` (T-16230). |
| two swapped argument or value registers (`$a0`/`$v1`), or a remainder in `$v0` instead of `$v1`, with global fields read in a date check | Read the fields through a `GameState *g` local (`g->unk_03F`). IDO still addresses them directly (`lui; lw %lo`), but the colouring ties break the original's way. The local takes one frame slot, so it can change the frame. DATE `func_80150ED4` and `func_80150C78` (T-16230). |
| two constants stored to display-record bytes share a register in the draft, the original keeps them apart | The field types decide: unsigned `u8` fields merge the constants with the later unsigned switch constants. Use a file-local record view with signed bytes at those offsets (`TaiikuActor44`, TAIIKU `func_801400D8`, T-11640); changing the shared struct would break other overlays. |
| the original copies the first word, then four words through `s1 = 1` | Peel the first iteration: `D[0] = rgb.v[0]; for (i = 1; i < 5; i++) ...` (TAIIKU `func_80138AA8`, T-11640). |
| the draft's jump table lacks the entry for an empty last case | Give the last empty case explicitly, `case 7: break;`. TAIIKU `func_8013C978` (T-11640). |
| one ugen temporary short in a sum of `u8` fields (texture coordinates `v + 8`) | A `(u8)` narrowing of the operand changes no stored value but adds the temporary. FAKE (TAIIKU `func_8013D9B4`, T-11640). |
| a promoted halfword counter gets an extra CVT copy in a second register, or the `lui` of the flag reload moves into a branch delay slot, where the original reloads counter and flag in every block | Read both through `u16` pointer views, `((u16 *)&D_801499A0)[1]` and `((u16 *)D_801499B0)[1]`, not through a `volatile` flag (a volatile `D_801499B2` stops the `lui` moving but costs a match wherever the flag is read after a block). FAKE. TAIIKU `func_8013BEF8` and `func_8013C0E4` (T-11640). |
| the high half of a 16.16 word is loaded with `lh` at offset +2 and written back as a halfword | Use an `s16` pointer view: `((s16 *)&D_80149968.unk_14)[1]`, and the same for a stack word `tmp` whose halves are written and read separately. FAKE (TAIIKU `func_8013D114`, `func_8013BB3C`, `func_8013C33C`, T-11640). |
| regdiff: "not allocated ... global X (-ve save)" for a narrow selector the original reloads after every call | A dead read of X at the very top of the function (`i = unk_03F; n = unk_03E;`, both overwritten later, no code emitted). It must come before the first call, and both selectors are needed. FAKE. `func_8006A2CC` (T-11690). Made `func_80067870` worse, so check with regdiff. |
| the w/h stores of a SPRT drawer are in the other order | `setWH(sprite, 8, 0x10);` instead of two statements. NAME_ENT `func_80137CA0` (T-11650). |
| the draft's jump table starts at the lowest case (`addiu t7,t6,-16`), the original's starts at 0 with an entry that jumps to the exit | An explicit empty `case 0: break;` (an entry of its own, not the default). TACO `func_80143B58` (T-16562). |
| a constant used once stored to a SPRT (`w = 0xC`, `h = 0x10`) takes `$fp` instead of the other one, and the store order is right | The first numbered constant wins a priority tie: `sprite->w = 0xC; sprite->h = 0x10;` on one line gives the original's `h` first and `0xC` in the register. TACO `func_801432F0` (T-16562). |
| the original unrolls a small loop (one peeled store plus groups of four) | Write the plain loop over array-indexed records, `(&D_800E6280.unk_0FC)[i]`; IDO unrolls it the same way, including the copy order 1, 2, 3, 0 of the 12-record initializer. NAME_ENT `func_8013635C` (T-11650). |
| constant or pointer in a1/a2/v1 in a small K&R function (TT, GEKO, TACO) | Known unsolved. Spend 10 minutes at most, then guard it and log the row. |

## Do not

- Don't assume a value in `v0`/`v1` means a promoted global. Check which value regdiff names.
- Don't try allocator options or compiler flags. They were exhausted in T-0014/T-0017/T-9800.
- Don't keep m2c's `temp_*` locals by default. They add values the original doesn't have.

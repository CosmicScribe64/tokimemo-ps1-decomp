# Switch release footage review: framing, HUD and settings

This page records a visual review of video footage of the Nintendo Switch release *ときめきメモリアル～forever with you～ エモーショナル* (Konami, 8 May 2025). The review was done on 2026-10-30 at the user's request. Frames were viewed in the built-in browser by seeking YouTube's own player, mostly at 1080p. Nothing was downloaded, no screenshot was saved, and no repository file other than this page was changed. Companion page, based on official screenshots and press: [[switch-remake-reference]]. Our design: [[phase4-design-2026-10-29]], [[widescreen-settings]].

Caveats:
- Streamer VODs add their own overlays (a camera, chat, a VTuber model). Those overlays are ignored in the notes below.
- The 2024 Nintendo Direct clip is from a pre-release build.
- Handheld and docked play were never shown side by side. Trailers show the same image inside a Switch OLED mock-up, and that image matched the docked captures. No difference between the two modes was seen.

## Synthesis

### Widescreen and framing

The Switch release uses three framing modes, chosen per screen:

1. **4:3 centre plus decorative wallpaper wings.** Used for VN scenes shown with original art (original-graphics mode, or scenes without new art), subgames and confession silhouettes. The wings are a static dark-green branded wallpaper. They are not drawn from the scene.
2. **4:3 centre plus functional side panels.** Used for the command screen in every graphics mode. The left wing shows biorhythm and the right wing shows the week's schedule. The PS1 HUD inside the 4:3 area stays as it was. The panels can be turned off with サイドパネル in the options. A seasonal checker continues behind the panels.
3. **Full 16:9.** Used only where Konami supplies **newly drawn** art (new-graphics VN scenes, opening, title backgrounds) or rebuilt menus (save screen, name entry, the name-calling picker). In these scenes the HUD is re-anchored rather than stretched: the location tag moves to the top-left, the date column to the right edge, the message window stays centred at its original width, and the checker strip extends across the full width.

Original pixel art is never stretched or extended to 16:9. It is scaled up with sharp pixels; no smoothing filter was seen.

### UI and HUD

- The HUD elements are unchanged in design: the stat board (体調/文系/理系/芸術/運動/雑学/容姿/根性/ストレス), the vertical date column, the 15-icon command grid, the seasonal checker and the hand cursor.
- The only new HUD content is the biorhythm and week-schedule side panels. Both show information that already exists in the game: the hidden biorhythm and the calendar.

### Message window and text

- The window frame, its proportions, the name column and the 3-line layout stay as they were.
- Text is offered in an original font or a new high-resolution font (キャラ表示 combinations). In new-graphics mode the command screen keeps the original font.
- The window does not widen in 16:9 scenes.

### Menus and settings

- Konami extended the original in-game option notebook instead of adding a separate modern menu. Its items: character display (4 choices), text display speed, command speed, icon mode, menu mode, cursor speed, side panel, sound. Each item has an explanatory help line in the message window.
- The save screen and name entry are re-laid-out for 16:9 but keep the original style.
- Button names in instructional text were rewritten for Switch (A button).

### QoL features shown

- Software-keyboard name entry.
- EVS name-calling intonation picker, with a preview for each of four options.
- Side panels showing biorhythm and the week's schedule.
- Font and art toggles.
- Gallery and textless opening as Deluxe extras.

The footage showed no text log or backlog, auto-advance, skip, or accessibility (colour or size) option. The footage was not exhaustive, so these may still exist.

## Recommendations for our port (fidelity-safe)

1. **Promote deferred item (iv) as an opt-in "Info side panels" setting for Class A only.** Draw biorhythm and the week schedule in window-space wings from existing state (live_hud_adapter, the calendar), and make sure they never touch the native Image. Show biorhythm only when the player opts in, because it exposes a hidden value. Default off. Name it after the Switch option (サイドパネル / "Side panels").
2. **Keep pillarboxing for every original-art scene.** This matches Konami's choice. Do not pursue a full-16:9 VN without new art.
3. **Style the modern text box to match the native window.** Use the same frame, proportions, name column and centred position, scaled to the window, and change only the font, as Konami's "+新フォント" does. Offer the choices "Original glyphs" and "Original window + readable font" rather than a generic panel. Keep the native frame width in wide mode instead of widening into the wings.
4. **Optional wallpaper wing fill is a separate decision.** If the user wants decorative wings like the Switch has, add display.wing_fill=wallpaper using a solid colour or a simple pattern built from original assets (for example the checker tile in a neutral palette). No new art and no Konami branding.
5. **Help line for every setting.** Copy Konami's one-sentence explanation for each option into the T-30002 pages, so players understand what is kept original. This fits the fidelity badge.
6. **Text with button names follows the prompt style.** Keep this layer-only, through the text layer, never in the native glyph Image.
7. **Name entry: typed-input path.** Accept keyboard or OS text input, then convert it into the existing native name buffer and its limits. Wing-free, presentation only.
8. **Not worth copying:** stretching the HUD to 16:9; widening the native message window; inventing new art or a branded wallpaper.
